# Ремонт квартир «Ровно»

Учебный лендинг для портфолио: вымышленная компания по ремонту квартир.

**Сайт:** https://iamzert.github.io/remont-rovno/

- Калькулятор стоимости: площадь (ползунком или цифрами), тип ремонта, жильё, доп. опции, срок
- Расчёт из калькулятора сам переносится в заявку
- Планировки квартир нарисованы в SVG, без картинок
- Раскрывающиеся вопросы на `<details>`, без JavaScript
- Адаптивная вёрстка, маска телефона, доступность с клавиатуры
- Картинка-превью для ссылок в мессенджерах (`og.png`)

Сделано на чистых HTML, CSS и JavaScript без библиотек.
